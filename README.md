# AP Hostel

AP Hostel is a web project for presenting hostel information and services through a responsive website.

## Features

- Hostel information and about section
- Room information
- Image gallery
- Contact page
- Responsive navigation
- SEO-related files such as `robots.txt` and `sitemap.xml`

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
index.html        Main page
about.html        About page
rooms.html        Room information
gallery.html      Gallery
contact.html      Contact page
css/              Stylesheets
js/               JavaScript
images/           Website images
favicons/         Favicon assets
```

## Getting Started

Clone the repository and open `index.html` in a browser, or serve the directory with a local HTTP server.

## Status

This repository contains the website source and can be improved further with testing, documentation, accessibility checks, and deployment configuration.
